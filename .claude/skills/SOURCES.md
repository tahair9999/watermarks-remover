# Third-party skills

Each skill's `name:` (and folder) carries a prefix chosen for this repo; the content is otherwise unmodified.

| Prefix / name | Upstream |
|---|---|
| `frontend-design` | https://github.com/anthropics/claude-code/blob/main/plugins/frontend-design/skills/frontend-design/SKILL.md |
| `taste-*` | https://github.com/Leonxlnx/taste-skill (`skills/*`), see `taste-LICENSE` |
| `vercel-*` | https://github.com/vercel-labs/agent-skills (`skills/*`) |
| `ui-ux-*` | https://github.com/anthropics/skills (`skills/*` and `template`); per-skill `LICENSE.txt` applies (docx/pdf/pptx/xlsx are source-available, not open source) |
| `design-loop` | https://github.com/jezweb/claude-skills/blob/main/plugins/frontend/skills/design-loop/SKILL.md |

Skills already named with the source prefix upstream (`vercel-*`) are not double-prefixed.
